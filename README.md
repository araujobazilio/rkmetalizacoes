# RK Metalizações - Landing Page

Landing page moderna para RK Metalizações, especializada em metalização artesanal de objetos afetivos.

## 🚀 Tecnologias

- **Next.js 14** - Framework React com SSR/SSG
- **TypeScript** - Type safety
- **Tailwind CSS** - Estilização
- **Zustand** - Gerenciamento de estado
- **Lucide React** - Ícones

## 📦 Instalação

```bash
npm install
```

## 🏃 Desenvolvimento

```bash
npm run dev
```

Acesse `http://localhost:3000`

## 🏗️ Build

```bash
npm run build
npm start
```

## 📁 Estrutura

```
app/
  ├── layout.tsx          # Layout principal
  ├── page.tsx            # Página inicial
  └── globals.css         # Estilos globais
components/
  ├── Header.tsx          # Cabeçalho
  ├── Hero.tsx            # Seção hero
  ├── About.tsx           # Sobre o processo
  ├── Products.tsx        # Produtos
  ├── Pricing.tsx         # Tabela de preços
  ├── BudgetForm.tsx      # Formulário de orçamento
  ├── BudgetModal.tsx     # Modal de orçamento
  ├── Shipping.tsx        # Informações de envio
  └── Footer.tsx          # Rodapé
public/
  └── images/             # Imagens do projeto
```
